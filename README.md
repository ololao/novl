# NOVL Core (v0.1)

Сетевой транспортный протокол и библиотека на Rust для инкапсуляции и передачи трафика через каналы с активным глубоким анализом пакетов (L7 DPI / ТСПУ) и защитой от активного сетевого зондирования.

---

## Архитектура и принципы работы

Протокол нейтрализует три ключевых вектора детекции цензуры: сигнатурный анализ L7, сканирование активными зондами (Active Probing) и атаки повторного воспроизведения (Replay Attacks).

* **Маскировка транспорта**:
  * `TlsChameleon`: генерация валидного TLS 1.3 ClientHello с аутентичным набором шифров, расширений и паддинга. 32-байтный сессионный токен аутентификации скрытно передается в поле `session_id`.
  * `HttpUpgrade`: маскировка под HTTP/1.1 WebSocket Upgrade с токеном в заголовке `Sec-WebSocket-Key`.
* **Фрагментация первого пакета (Split Handshake)**:
  * Разделение первого сетевого сегмента (TLS ClientHello или HTTP Upgrade) на части со смещением и миллисекундным джиттером. Нарушает сборку пакетов в кольцевом буфере ТСПУ.
* **Перенаправление зондов через `splice(2)`**:
  * Неавторизованные запросы и сетевые сканеры прозрачно перенаправляются на резервный веб-сервер (Nginx). Пересылка выполняется через кольцевые буферы ядра Linux без копирования данных в пространство пользователя.
* **Шардированный фильтр повторов (Anti-Replay)**:
  * 32 независимых мьютекс-шарда со скользящим окном (TTL 90-120 с) блокируют повторную отправку перехваченных пакетов без взаимных блокировок при высокой параллельной нагрузке.
* **Мультиплексирование UDP-over-TCP (UoT)**:
  * Инкапсуляция UDP-датаграмм (DNS, WebRTC, VoIP) внутри аутентифицированного потока ChaCha20-Poly1305.
* **C-ABI экспорт (`libnovl.so`)**:
  * Библиотека предоставляет заголовочный файл `include/novl.h` для интеграции в Android (`VpnService`), iOS и сторонние прокси-клиенты.

---

## Криптографический стек

* **Деривация ключей**: BLAKE3-KDF (`context = "NOVL-v1-MASTER-KEY"`).
* **Аутентификация рукопожатия**: соль (8 байт) + метка времени (8 байт) + BLAKE3-MAC (16 байт).
* **Симметричное шифрование**: ChaCha20-Poly1305 с инкрементальным nonce. 4-байтный заголовок фрейма `[Payload Length || Padding Length]` защищен через AAD.

## Сборка

### Требования:
* Rust 1.77+ и Cargo.

### Компиляция:
```bash
cargo build --release
```

Артефакты сборки (`target/release/`):
* `novl-server` — серверная служба.
* `novl-client` — клиентский CLI-демон с локальным SOCKS5.
* `libnovl.so` / `libnovl.a` — динамическая и статическая библиотеки C-ABI.

### Тестирование:
```bash
cargo test
```

## Запуск

### Сервер:
```bash
novl-server --listen 0.0.0.0:7443 --fallback 127.0.0.1:8080 --secret "YOUR_SECRET_KEY"
```
Параметры:
* `-l, --listen <ADDR>` — адрес прослушивания (по умолчанию `0.0.0.0:7443`).
* `-f, --fallback <ADDR>` — адрес локального веб-сервера для перенаправления зондов (`127.0.0.1:8080`).
* `-s, --secret <KEY>` — общий секретный ключ.

### Клиент:
```bash
novl-client --socks5 127.0.0.1:10800 --server YOUR_SERVER_IP:7443 --sni addons.mozilla.org --mode tls --secret "YOUR_SECRET_KEY"
```
Параметры:
* `-b, --socks5 <ADDR>` — локальный адрес SOCKS5-прокси (`127.0.0.1:10800`).
* `-s, --server <ADDR>` — адрес удаленного сервера (`YOUR_SERVER_IP:7443`).
* `--sni <DOMAIN>` — домен для поля SNI или заголовка Host (`addons.mozilla.org`).
* `-m, --mode <tls|http>` — режим транспорта (`tls` или `http`).
* `--split-pos <N>` — позиция разделения первого пакета (по умолчанию `5`).
* `--split-delay <MS>` — задержка между частями пакета в миллисекундах (по умолчанию `1`).
